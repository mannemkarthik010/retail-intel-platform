# Core
#
# scikit-learn/numpy/scipy/joblib are PINNED, not floating, and that matters:
# reports/models/*.joblib are pickled scikit-learn estimators, and unpickling
# one requires the same library internals that pickled it. Deploying this to
# a host that resolved `scikit-learn>=1.3` to a different version than the
# 1.8.0 these artifacts were trained on made /api/explain and /api/simulate
# fail on every request with `ModuleNotFoundError: No module named '_loss'`
# -- sklearn had relocated that internal Cython module, so the pickle
# referenced a path that no longer existed. Textbook train/serve skew: the
# code was fine, the model file was fine, the two ENVIRONMENTS disagreed.
#
# If you retrain (scripts/run_pipeline.py) on newer versions, bump these
# pins in the same commit that commits the regenerated .joblib files.
pandas==2.3.3
numpy==2.4.2
scipy==1.17.1
scikit-learn==1.8.0
matplotlib>=3.7   # figures only (scripts/make_report_figures.py), never
                  # imported on the serving path -- safe to float
joblib==1.5.3 # persists the trained point/quantile GBMs (reports/models/*.joblib)
              # for reuse by src/explain.py and src/scenario.py -- see scripts/run_pipeline.py

# Serving
flask>=3.0

# Agent (real LLM backend, optional -- only needed if ANTHROPIC_API_KEY or
# OPENAI_API_KEY is set; both backends are plain HTTP via `requests`, no
# vendor SDK)
requests>=2.31

# Agent, Bedrock backend only (optional -- only needed if BEDROCK_MODEL_ID
# or LLM_BACKEND=bedrock is set; see src/agent.py::BedrockLLM). Unlike the
# two HTTP-only backends above, boto3 is a deliberate exception to the
# "no vendor SDK" pattern -- AWS auth is SigV4-signed, not a bearer token a
# plain `requests` call can attach easily, and boto3 is the standard SDK
# needed anyway for the S3/Lambda/SageMaker calls in infra/. NOT
# installable in the build sandbox this repo was assembled in (pip installs
# beyond a pre-cached set were blocked there -- see infra/README.md's
# disclosure section), so BedrockLLM's dispatch/tool-calling logic is only
# tested with a mocked boto3 (tests/test_agent.py), never a real one.
# boto3>=1.34

# Dev / testing

#  the stdlib `unittest` -- see docs/ARCHITECTURE.md for why)
# pytest>=7.4

# Production WSGI server (NOT installable in the build sandbox this repo was
# assembled in -- pip installs beyond a pre-cached set were blocked there, so
